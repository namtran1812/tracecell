# Contributing

TraceCell welcomes contributions in robotics simulation, distributed event processing, AWS infrastructure, observability, frontend tooling, testing, and performance engineering.

Principles:

1. Subsystems remain independently observable.
2. Correlation uses explicit identifiers.
3. Out-of-order delivery must be supported.
4. Behavior changes require tests.
5. Performance claims require reproducible benchmarks.
6. AWS integrations should preserve locally testable core logic.
